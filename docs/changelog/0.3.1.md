# 0.3.1

Unreleased. Fixes to 0.3.0; the config and `.basalt` formats stay as they are.

- **Experts on the SSD are said everywhere.** Any expert only the file holds gives one engine warning: `N experts on SSD (X GiB)
  · free X GiB RAM`, plus the model's other hints. The server console repeats it, `/metrics` carries `engine.spill` (`experts`,
  `total`, `bytes`; `null` when nothing spilled) and each request's `ssd_share`, and the stats page turns its Experts block amber
  with an SSD tier. [memory floors](../running.md#memory-floors)
- **One RAM reserve.** `--ram-reserve-mib` (default 2048) is the RAM left free for the rest of the system; the old floors (a
  percentage of RAM, a fixed late-memory figure, a file-cache minimum) are gone. The prompt and image host buffers are allocated
  first and the RAM tier then takes the free RAM less the reserve and the driver's page tracking, so one place short no longer
  sends whole layers of experts to the file. The prompt ring of second-card and file reads is capped instead of growing with the
  experts left in the file, and a prompt no longer stages a whole chunk's embeddings and Engram rows. The RAM copy allocates its
  checkpoint blocks and holds the RAM of its page-locked prompt buffers before sizing itself; its estimate of what it takes later
  is gone. [memory floors](../running.md#memory-floors)
- **One RAM guard.** The serving RAM guard runs in the shared serve path and holds the reserve, so every model sheds parked
  conversations, holds new requests and stops one at critical RAM alike. `--ram-reserve-mib 0` turns it off, for machines where it
  stopped requests that would have fit. [memory floors](../running.md#memory-floors)
- **Default context 8,192.** Flash-Next's was 4,096; `--max-context` still sets it. [models](../models/index.md)
- **Start lines.** Each entry's line shows the drafting the engine will run (`spec=N`); a shared idle sleep is said once, on the
  shared line; the conversation folder line shows only with `--debug`; a load reads `loading MODEL (N waiting)` and a swap
  `swap OLD -> NEW (N waiting)`.
- **`--max-payload-mib` sets the largest request body.** The server reads up to 256 MiB by default; a bigger body gets a 413
  naming the limit. [configuration](../configuration/index.md)
