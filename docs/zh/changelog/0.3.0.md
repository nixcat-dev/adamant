# 0.3.0

[English](../../changelog/0.3.0.md)

2026-11-05。从源码构建：[构建](../building.md)。配置格式有变化，请先读[升级](#升级)。`.basalt` 格式仍是版本 2。

## 要点

- 模型 adapter：模型自己的代码放在自己的目录里（`src/models/<model>`），共享代码只通过 adapter 看到模型，引擎注册自己
  支持的模型。新增一个：[新增模型](../adding-a-model.md)。
- 路由：配置文件里列出多个条目，每个条目命名一个 pack，请求的 `model` 字段选其中一个，同一时间只加载一个。客户端会等待
  换模型；名字写错是 404，加载失败是 503 并命名该模型，服务器不会退出。[模型与路由](../configuration/models.md)
- 配置文件 v2 形状：`models` 列表、共享的 `engine` 块和 `server` 块。

## 升级

1. 重新构建：[构建](../building.md)。Linux 构建需要 GCC 13 或更新版本。
2. **配置格式有变化。** 没有 `models` 的配置在启动时会被拒绝：`Basalt requires v2 config, please upgrade`。
   `python3 tools/migrations/config_v1_to_v2.py basalt_config.json -o basalt_config.v2.json` 会写出新形状，旧文件保持不动。
   [迁移](../configuration/models.md)
3. `.basalt` 文件照常可用。
4. 未合并的 pull request 需要 rebase：`src/core`、`src/prefill`、`src/kernels` 和 `src/program` 大部分都移动了。模型代码在
   `src/models/<model>` 和 `include/basalt/models/<model>` 下，服务器方言在 `serve/models` 下。
   新增模型：[新增模型](../adding-a-model.md)。

## 近期变更

自 0.2.1 以来的变更。

### 新增

- 一个服务器循环服务所有配置的模型，`/health`、`/metrics` 和 `/v1/status` 报告换模型与每个模型的状态；
  `/v1/models` 列出每个配置条目及其状态。
- 统计页面顶部是模型选择器：选一个模型就加载它，顶部显示加载进度。
- `--lazy` 保留 `--vision dynamic`，即第一次请求时在引擎内编码；只有 sidecar 编码器会被丢掉。
- 工具结果里的图像在任何 API 上都能进入提示词；放不进去的会被拒绝并记入日志。

### 修复

- 带坏 UTF-8 的引擎行不再让服务器的读取线程停止。
- Grammar：带非 ASCII 字符的闭合标签可以解析。
- 引擎拒绝的空闲睡眠只警告一次，然后等下一个请求。
- 第一个 SIGTERM 会忽略后续的，因此引擎退出和它的磁盘溢出不会被截断。
- `/metrics` 在 Windows 上报告 GPU：NVML 从 `nvml.dll` 读取。

### 移除

- `basalt-overlap` 和 `basalt-concurrent`，以及没有任何东西能到达的代码，其中包括朴素的 S2 decode 与 S2 GEMV kernel，
  以及校验窗口的 S2 专家分支。
