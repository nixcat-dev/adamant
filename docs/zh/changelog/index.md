# 变更日志

[English](../../changelog/index.md)

发布记录,最新在前。分叉点之前的条目属于 Basalt;Adamant 从 Ada 移植起开始自己的历史。版本号是 0.x:小版本发布新增一个模型或其他重大变化;补丁发布带来修复与较小的特性,也可能改名或移除某个标志(被移除或改名的标志会让配置失效,因为 Basalt 不保留任何兼容垫片,所以每个条目的 Upgrading 一节会列出它们)。每个发布对应一个附注标签 `vX.Y.Z`,并带有收录该条目的 GitHub Release;不提供预构建的二进制文件,请从源码构建([构建](../building.md)),或打包已构建的目录树([平台](../platforms.md#发布归档))。

| 版本 | 日期 | 概要 |
| --- | --- | --- |
| [0.3.2](0.3.2.md) | 2026-11-08 | 更快的干净构建，`tools/package_release.py` 打包 Linux 与 Windows x64 归档，安装目录能在 `bin/` 旁边找到自己的文件，RAM 层给文件缓存保留下限，Q6_K 短行与 AVX-512 精确行 kernel。 |
| [0.3.1](0.3.1.md) | 2026-11-08 | SSD 上的专家在日志、控制台和统计页面都会说明；每个并行槽位都会 drafting；对等卡共用一条提示词路径；更快的 decode kernel；新增 pack；所有模型共用一份 RAM 保留量与守卫（`--ram-reserve-mib`）；默认上下文 8,192。 |
| [0.3.0](0.3.0.md) | 2026-11-05 | 模型 adapter 注册表、在配置条目之间切换的路由，以及配置文件 v2 形状。 |
| [0.2.1](0.2.1.md) | 2026-11-03 | 图像来源随请求来源而定;质量以 BF16 参考衡量;新增采用 Q8_0 稠密投影的 NVFP4 pack。 |
| [0.2.0](0.2.0.md) | 2026-11-01 | `.basalt` 格式版本 2,冷启动 decode 提速约 13%,可选的有损路由标志,思考循环保护。 |
| [0.1.0](0.1.0.md) | 2026-10-29 | 首个带标签的发布:引擎现状,以及 2026-10-15 以来的变更。 |
