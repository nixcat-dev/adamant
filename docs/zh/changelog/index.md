# 变更日志

[English](../../changelog/index.md)

发布记录,最新在前。分叉点之前的条目属于 Basalt;Adamant 从 Ada 移植起开始自己的历史。版本号是 0.x:小版本发布新增特性或更改标志与默认值(被移除或改名的标志会让配置失效,因为 Basalt 不保留任何兼容垫片);补丁发布只做修复。每个发布对应一个附注标签 `vX.Y.Z`,并带有收录该条目的 GitHub Release;不提供二进制文件,请从源码构建([构建](../building.md))。
