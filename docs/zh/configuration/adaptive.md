# 自适应专家层

[English](../../configuration/adaptive.md)

仅 Flash-Next。GPU 只持有部分专家。自适应层统计会话路由到哪些专家，并在解码旁边的轮次里把最常用的专家
搬进 VRAM。这里的默认值是在本机测得的最快值。

## 一轮怎么做

路由计数给不在 VRAM 中的专家排名。一轮把被路由最多的专家换入，换掉驻留专家里被路由最少的。服务器上的一轮
占用三个窗口：拷出、在旁路流上拷入，然后使用。每轮之后计数会衰减。主卡上所有层一起排名；对等卡上主卡先取
它那一份。搬运专家会改变舍入，因此开启自适应时的输出在不同运行间不是逐位一致的。

## 设置

| 设置 | 默认值 | 取舍 |
| --- | --- | --- |
| `adapt-every` | 服务器上 1，层拆分时 4 | 轮次越少越晚，链路开销越小，但话题切换或新引擎要等 N 个窗口。 |
| `adapt-swaps` | 96 | 轮次越大追得越快，搬的字节也越多（每个 NVFP4 专家单向约 2.6 MiB）。RAM 副本保留 4 倍 N 个空位。 |
| `peer-adapt-swaps` | `adapt-swaps` | 相同，但在对等卡的链路上。`0` 冻结对等层。 |
| `adapt-decay` | 0.85（层拆分时 0.7） | 越低越快跟随话题切换。越高越能保持长期放置。 |
| `expert-profile-save` | 关闭 | 保存放置；延续同样的负载会从它起步，换一种负载就会起步在错的位置。 |

`done` 行里的 `hit=` 只统计主卡 VRAM 的查找，所以 `hit` 更高不一定更快。要比 `tg`。

卡比较小的时候，更小的轮次可能更快，因为每一轮过链路的专家更少。[basalt-probe](../probe.md) 会在你的机器上试这些值，更小的轮次也包括在内。
